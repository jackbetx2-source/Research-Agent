Project Overview

轻量研究 Agent

项目围绕研究写作、文献综述和文献评估三类任务组织，把多源检索、分析、综合和引用输出整合到同一个 Web 工作流中。

01

Systematic Review

文献综述

面向需要成体系梳理论文集合的综述任务。它会从 arXiv、OpenAlex、PubMed 和 Crossref 聚合检索结果，去重后批量提取研究问题、方法路线、核心发现和局限。

  • 适合用于综述开题、领域扫描、相关工作整理和论文池初筛。
  • 支持论文数量、arXiv 分类、时间范围和引用格式设置，便于控制检索范围。
  • 输出主题聚类、共识与分歧、研究空白、逐篇注释和 APA、IEEE 或 BibTeX 引用。
  • 帮助快速判断一个领域已经做了什么、还缺什么、哪些论文值得优先精读。
02

Literature Assistant

文献分析

面向已经收集到手的论文和资料。可以提交 DOI、arXiv 链接、论文页面或多个 PDF，系统会补全元数据、抽取正文证据，并生成便于比较的文献评估表。

  • 适合用于阅读清单整理、重点论文速读、文献筛选和多篇论文横向比较。
  • 支持多 PDF 队列上传，并可与 DOI、arXiv 链接或论文网页混合分析。
  • 从贡献、方法、证据强度、优势、局限和后续建议等维度形成评估结果。
  • 帮助把零散材料转化为可复用的笔记、对比表和后续写作依据。
03

Research Workspace

研究报告

面向从研究问题到可阅读报告的全流程写作。它会把主题拆解为背景梳理、证据检索、观点比较和批判性分析，再整合成结构清晰、可继续编辑的 Markdown 初稿。

  • 适合用于选题调研、方向摸底、技术趋势梳理和争议问题分析。
  • 自动组织研究脉络、关键证据、不同立场和可追问的问题，减少从零搭框架的时间。
  • 默认采用快速模式，并能在研究完成后提取相关文献，衔接后续文献分析。
