Project Overview

一个本地运行的多步骤研究 Agent

这个项目可以根据用户输入的 topic，自动完成意图理解、并行研究和报告整合， 最后生成一份结构化 Markdown 研究报告。

01

理解研究意图

系统会先分析输入主题，提炼研究范围、核心问题和写作方向。

02

并行研究分支

多个 LLM 分支会从不同角度同时展开研究，减少单一路径带来的遗漏。

03

自动整合报告

综合节点会汇总各分支内容，输出可复制、可保存的 Markdown 最终报告。

04

本地网页交互

通过浏览器输入 topic、选择快速模式、查看运行状态和复制最终结果。

Workflow

当前工作流

  1. 输入研究主题
  2. LLM 分析研究意图
  3. 三个研究分支并行生成内容
  4. 综合节点生成最终报告
  5. 保存到 outputs 目录并显示在网页中
